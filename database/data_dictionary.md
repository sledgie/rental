# Data dictionary

> Generated by `database/tests/generate_docs.mjs` from the live schema (every migration in database/migrations applied, in order, to PostgreSQL). Do not edit by hand; change the migrations and regenerate.

147 tables, 17 views, 30 public functions. Money columns are `numeric(14,2)` in the record's currency. Every organization-owned table has `organization_id` and a composite `(organization_id, id)` key that child tables reference, so rows can never point across organizations.

**How to read the access column:** *read* / *write* name the permission keys that the RLS policies require (see `permissions` in `002`/`009`; the owner role always passes). "member" means any active member of the organization.
